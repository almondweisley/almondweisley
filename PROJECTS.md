# Projects

Full write-ups for the projects featured on my profile, in the same order. The README links here so the main page stays scannable. Repos marked private aren't public yet, so this write-up is the place to read about them for now.

<a id="safari-salama"></a>

## 🚌 SAFARI-SALAMA

A matatu route optimization and safety system for commuters. Maps common routes across Nairobi and surfaces safety data so riders can choose better trips before they board. A companion driver app sits alongside the rider app.

- **Stack:** Python backend · Flutter rider and driver apps · PostgreSQL
- **Repo:** Private for now

<a id="signalgrid"></a>

## 📱 SignalGrid

An autonomous community situational awareness system. Community members submit signals as text, voice, images or short video, and the system reasons over them to detect emerging events and turn raw reports into actionable intelligence.

- **Stack:** Flutter · Dart · Node.js + MongoDB
- **Repo:** [github.com/almondweisley/SignalGrid](https://github.com/almondweisley/SignalGrid)

<a id="edumanage"></a>

## 🏫 EduManage

A school management system. The Django REST backend covers students, staff, fees, assessments, timetables, inventory, communication and reports, with background jobs running on Celery. A React Native admin app sits on top.

- **Stack:** Django REST Framework · SimpleJWT · Celery · React Native + TypeScript
- **Repo:** Private for now

<a id="whetstone"></a>

## 🪨 Whetstone

Coding exercises that carry proof of their own solvability. A language model drafting an exercise has no way to know whether it can be solved, so Whetstone makes it prove each one before it reaches a student. No more evenings lost on a broken problem 14.

- **Stack:** Django · Flutter · Docker
- **Repo:** [github.com/almondweisley/whetstone](https://github.com/almondweisley/whetstone)

<a id="azani-isp"></a>

## 🌐 Azani ISP Information System

A Java Swing desktop app on MySQL for an internet service provider. It registers institutions, captures payments, records site visits and equipment orders, manages subscriptions and upgrades, runs the monthly billing cycle, and produces reports. Built for SCO 200 (Object Oriented Programming II) at Kenyatta University.

- **Stack:** Java 17 · Swing · MySQL
- **Repo:** [github.com/almondweisley/isp_azani](https://github.com/almondweisley/isp_azani)
